## 2. Software Purpose

### Development Methodology
- **Methodology**: Agile

### Reason for Selection
Agile is more suitable for this small desktop application because requirements can be adjusted gradually. Compared with Waterfall, Agile supports iterative development, testing, and improvement, which fits our team schedule and project scope.

### Potential Use Cases / Target Market
- For students to track study time
- Help improve learning efficiency
- Visualize time spent on each subject
- Target users: students, self-learners
